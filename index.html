游戏内预设上限（金手指已按这些值钳制）

    

      
参数游戏内上限金手指的处理

      
粮草 / 石材 / 铁矿 / 木材四项合计不超过仓库容量：Lv1 60 万 → Lv5 1000 万超出的输入自动截断并提示

      
银两无上限（挂机产银不受仓库容量限制）可自由设置，「补满」时取仓库容量值

      
声望无用途、无上限（源码里的预留字段）可自由设置

      
军令10（maxMilitaryOrder 在迁移函数里写死）输入自动钳制到 0–10

      
建筑 / 科技 / 仓库等级均 5 级按钮直接拉满 5 级

      
官府城数量5 座（MAX_GOV）未提供超限功能

      
武将数量5 + ⌊(主公等级 − 1) / 5⌋超限时弹窗询问，确认后才强制加入

      
主角 / 武将等级无硬上限（升级经验 = 等级×100 + (等级−1)×50）可自由设置，面板提示当前名额上限

    


    
主题换肤（游戏 + 面板一起换）

    

      
2 套配色

      
    
        
  • 鎏金（默认）：游戏原始配色，黑金三国风。选它即可随时还原。
    • 
        
  • 深色：把游戏的暖棕背景（#1a1410 / #2a2015 / #5a4a2a 等）与金色系整体换成黑白灰（#1e1e1e / #252526 / #3c3c3c / #d4d4d4），观感接近代码编辑器；面板在深色下还会一并换成等宽字体。
    • 
        
  • 切换入口：金手指面板的「主题」分区（点色块），或本页右上角的圆点。两边各自记忆，互不干扰。
    • 
      

      
怎么实现的

      
先把游戏页面自身 <style> 与元素内联 style 里的色值做映射替换（原始值留档，可无损还原），再用 MutationObserver 盯着游戏动态新建的元素同步换色 —— 所以弹窗、卡片这些后生成的界面也会跟着变色。

      
面板自身也是同一套主题变量驱动的，所以换肤后游戏和面板看起来是一体的。
