## 注入面板（电脑端）

1. 打开游戏页面 → F12 打开控制台
2. 从「① 注入面板」复制脚本粘贴回车，右下角出现悬浮面板

面板功能：资源/兵力/军令、主公（类型/等级/改名）、建筑科技仓库、武将招募与等级、装备获取、攻击倍率、主题换肤（连游戏配色一起换）。

## 手机端（在线改档）

存档在游戏域的 localStorage 里，跨域页面读写不到，所以需要一次「桥接书签」中转：

1. 在游戏页面点「桥」书签 → 存档复制到剪贴板并跳到编辑页
2. 编辑页改数据 → 生成回写链接 → 复制
3. 回游戏页面打开链接 → 再点一次「桥」书签 → 写回并刷新
